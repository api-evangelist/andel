## Instructions for AI Agents

## Docs

- [Andel Developer Docs](https://build.andel.org/home/welcome/welcome.md): APIs, integration guides, and reference material for partners building with Andel.
- [Data Exchange API](https://build.andel.org/dataexchange/overview/overview.md): Real-time interchange of member purchases between Andel and counterparty plans or PBMs.
- [ESI Compatibility](https://build.andel.org/dataexchange/overview/esi-compatibility.md): How the Data Exchange API maps to the Express Scripts CDH 1500-byte accumulator format.
